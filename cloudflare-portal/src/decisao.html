🎯

Você tem 2 caminhos — ambos funcionam!

Opção 1: Fazer um fork do Mifos Pay (app já pronto, open-source, nas lojas)
Opção 2: Criar um app Flutter do zero consumindo a API do Fineract

Para maioria dos casos, o Flutter do zero é mais recomendado — mais flexível, mais fácil de controlar e com mais devs disponíveis no mercado.

💡

Por que Flutter e não o Mifos Pay direto? O Mifos Pay é em Kotlin Multiplatform (KMP) — uma tecnologia mais difícil de encontrar devs. O Flutter tem muito mais desenvolvedores, tutoriais e comunidade no Brasil. E a API do Fineract funciona igual para os dois.

Código de exemplo: conectar no Fineract

Básico para começar em 30 minutos

1. Cliente HTTP (dio + interceptor)

// core/api/fineract_client.dart import 'package:dio/dio.dart'; class FineractClient { final _dio = Dio(BaseOptions( baseUrl: 'https://seu-banco.app/fineract-provider/api/v1', headers: { 'Fineract-Platform-TenantId': 'default', 'Content-Type': 'application/json', }, )); FineractClient(String token) { _dio.interceptors.add(InterceptorsWrapper( onRequest: (options, handler) { options.headers['Authorization'] = 'Bearer $token'; handler.next(options); }, )); } // Buscar saldo da conta Future<Map> getAccountBalance(int accountId) async { final res = await _dio.get('/savingsaccounts/$accountId'); return res.data; } // Realizar depósito / crédito Future deposit(int accountId, double amount) async { return await _dio.post( '/savingsaccounts/$accountId/transactions', queryParameters: {'command': 'deposit'}, data: { 'amount': amount, 'locale': 'pt', 'dateFormat': 'dd/MM/yyyy', 'transactionDate': _today(), }, ); } String _today() { final d = DateTime.now(); return '${d.day.toString().padLeft(2,"0")}/${d.month.toString().padLeft(2,"0")}/${d.year}'; } }

Opção 2 — App Pronto

🔱 Fork do Mifos Pay (Kotlin KMP)

Se quiser usar o app já pronto, aqui está como fazer o fork e personalizar.

⚠️

Quando usar o fork? Recomendado apenas se você já tem experiência com Kotlin e quer lançar um MVP rapidamente sem criar UI do zero. Para longo prazo, Flutter é mais sustentável.

📋

O que o Mifos Pay já tem pronto

  • ✅ Login + autenticação OAuth2 no Fineract
  • ✅ Dashboard com saldo da wallet
  • ✅ Enviar dinheiro P2P
  • ✅ Gerar e escanear QR Code
  • ✅ Histórico de transações
  • ✅ Perfil do usuário
  • ✅ Funciona em Android + iOS
  • ✅ Já publicado nas lojas
  • ⚠️ Design básico — precisa de customização
  • ⚠️ Kotlin KMP — curva de aprendizado
🔧

Como fazer o fork do Mifos Pay

1

Fork no GitHub

Acesse github.com/openMF/mifos-pay → clique em Fork → cria uma cópia no seu repositório.

2

Configurar URL do Fineract

No arquivo de configuração, troque a URL do servidor Fineract pelo endereço da sua instância.

3

Trocar branding (logo, cores)

Substitua logos, ícones do app, paleta de cores e nome do aplicativo. Isso já te dá um app white-label.

4

Publicar nas lojas

Gerar APK/IPA, criar conta no Google Play Console e App Store Connect, publicar com seu bundle ID.

5

Adicionar features brasileiras

PIX, boleto, notificações em português — adaptações necessárias para o mercado BR.

Guia Prático

🚀 Passo a passo: Flutter do Zero

Do ambiente de desenvolvimento até o app nas lojas — sequência completa.

⚙️

Fase 1: Configurar ambiente

1 dia

Instalar Flutter SDK

Download em flutter.dev → rodar flutter doctor → instalar Android Studio + Xcode

Criar projeto Flutter

flutter create meu_banco → abre no VS Code ou Android Studio

Adicionar packages

No pubspec.yaml: dio, riverpod, flutter_secure_storage, local_auth, qr_flutter

Testar no emulador

flutter run → app abre no emulador Android ou simulador iOS

🏗️

Fase 2: Backend Fineract

1-2 semanas

Subir Fineract com Docker

docker compose up no repositório do Fineract → servidor rodando em localhost:8443

Testar API no Swagger

Acessar localhost:8443/swagger-ui → testar criar cliente, conta, transações

Configurar produto Conta Corrente

Via API ou interface Mifos X: criar produto de savings, definir charges, currency BRL

Deploy em produção

Docker + AWS ECS ou Kubernetes (GKE/EKS) com HTTPS e domínio próprio

📱

Fase 3: Telas do App

2-4 semanas

1. Splash + Onboarding 2 dias

Logo, animação, telas de boas-vindas, cadastro com CPF

2. Login + PIN + Biometria 2 dias

OAuth2 no Fineract, armazenar JWT, TouchID/FaceID

3. Home — Saldo e Resumo 3 dias

GET /savingsaccounts/{id} → mostrar saldo, últimas transações

4. Extrato 2 dias

GET /savingsaccounts/{id}/transactions → lista com filtro por data

5. Transferência / PIX 4 dias

Buscar beneficiário, confirmar, chamar BaaS + Fineract withdrawal/deposit

6. Cobrar / QR Code 3 dias

Gerar QR PIX (via BaaS), exibir para o pagador, ouvir webhook de confirmação

🏪

Fase 4: Publicar nas Lojas

1 semana

Google Play Console

Conta de desenvolvedor ($25 taxa única) → upload APK/AAB → review 1-3 dias

App Store Connect

Apple Developer Program ($99/ano) → upload IPA → review 1-7 dias (mais rigoroso)

Configurar Firebase

Analytics + Crashlytics + FCM (push notifications) → integrar no Flutter

🔌 Como o Flutter se conecta ao Fineract

O app Flutter consome a API REST do Fineract diretamente. Simples assim.

🗺️

Mapa: Tela → API Fineract

Fluxo de autenticação

// Passo 1: Login → recebe token JWT POST /api/v1/authentication { "username": "joao.silva", "password": "minha_senha" } // Resposta: { "base64EncodedAuthenticationKey": "am9hbzpzZW5oYQ==", "authenticated": true, "userId": 42, "roles": ["CLIENTE"] } // Passo 2: Guardar token com segurança // No Flutter → flutter_secure_storage await storage.write( key: 'fineract_token', value: 'Bearer am9hbzpzZW5oYQ==' ); // Passo 3: Todas as chamadas usam o token dio.options.headers['Authorization'] = token;
✅

Gerar SDK automaticamente! O Fineract tem uma spec OpenAPI 3.0 completa. Você pode rodar openapi-generator e ele cria automaticamente todas as classes Dart/Flutter para chamar a API — sem precisar escrever nenhum client na mão.

💡

Self Service Plugin O openMF/selfservice-plugin é um plugin Spring Boot que adiciona ao Fineract endpoints específicos para o cliente final (não para operadores). Recomendado instalar para o app mobile ter endpoints mais simples e seguros.

🎯 Recomendação final: qual caminho tomar?

Baseado no seu contexto, aqui está a recomendação mais clara possível.

🐦

Flutter do Zero

Escolha se você:

  • ✅ Quer design personalizado
  • ✅ Tem (ou vai contratar) dev Flutter
  • ✅ Quer total controle do código
  • ✅ Pensa a longo prazo
  • ✅ Tem 2+ meses para desenvolver
🔱

Fork Mifos Pay

Escolha se você:

  • ✅ Precisa lançar MVP em < 2 meses
  • ✅ Tem dev Kotlin no time
  • ✅ Design básico é suficiente
  • ✅ Quer validar ideia rapidamente
  • ⚠️ Depois refaz em Flutter
⚡

Híbrido (Recomendado)

Melhor dos dois mundos:

  • 🚀 Fork Mifos Pay para MVP (semana 1-8)
  • 🔧 Fineract rodando em paralelo
  • 🎨 Começa Flutter customizado (mês 3+)
  • 🔄 Migra usuários do fork para o Flutter
  • ✅ Valida + escala

🚀 Próximos passos concretos

Comece hoje com esses 3 comandos e você já tem um app bancário funcional localmente em menos de 1 hora.

# 1. Subir Fineract com Docker
git clone https://github.com/apache/fineract.git
cd fineract && docker compose up -d

# 2. Criar app Flutter
flutter create meu_banco_app
cd meu_banco_app

# 3. Adicionar package HTTP
flutter pub add dio riverpod flutter_secure_storage
